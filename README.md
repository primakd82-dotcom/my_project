#Банковское приложение

##Описание проекта

Создание банковского приложения с различными функциями.

##Структура проекта

src/masks.py - модуль, содержащий функции маскировки части данных номера карты или номера банковского счета

src/widget.py - модуль, содержащий функцию маскировки части данных типа и номера карты

src/processing.py - модуль, содержащий функцию фильтрования и сортировки

##Установка

poetry install

##Пример использования

Для того, чтобы запустить проект, необходимо сначала скопировать репозиторий по ссылке:

https://github.com/primakd82-dotcom/my_project.git

Либо клонировать проект:

git clone https://github.com/primakd82-dotcom/my_project.git

Далее установить зависимости.

Затем можно запустить файл, например, widget.py, следующим образом:

python widget.py
