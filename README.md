# Банковское приложение

## Описание проекта

Создание банковского приложения с различными функциями.

## Структура проекта

src/masks.py - модуль, содержащий функции маскировки части данных номера карты или номера банковского счета

src/widget.py - модуль, содержащий функцию маскировки части данных типа и номера карты

src/processing.py - модуль, содержащий функцию фильтрования и сортировки

## Установка

    poetry install

## Пример использования

Для того, чтобы запустить проект, необходимо сначала скопировать репозиторий по ссылке:

https://github.com/primakd82-dotcom/my\_project.git

Либо клонировать проект:

git clone https://github.com/primakd82-dotcom/my\_project.git

Далее установить зависимости.

Затем можно запустить файл, например, widget.py, следующим образом:

    python widget.py

## Тестирование функций

В отдельной папке tests созданы тесты для каждой функции. Название каждой функции для теста имеет префикс test.

Для тестирования установлен фреймворк pytest.

Добавлена библиотека pytest-cov командой:

    poetry add --group dev pytest-cov

Запуск тестов осуществляется командой  в терминале.

Команды, чтобы запустить тесты с оценкой покрытия:

	pytest --cov - при активированном виртуальном окружении;
	poetry run pytest --cov – через poetry;
	pytest --cov=src --cov-report=html – чтобы сгенерировать отчет о покрытии в HTML-формате, где src – пакет с модулями, которые тестируем.

* Модуль test_masks.py

Cодержит тесты для обработки функций get_mask_card_number, get_mask_account.

Применены декораторы @pytest.fixture и @pytest.mark.parametrize.

Проверяются различные данные на входе с получением необходимого результата:

    Пример: "5555222233337777" -> "5555 22** **** 7777"

Тест также проверяет корректность обработки некоторых некорректных данных.

При вводе некорректных данных функция выбрасывает исключение ValueError с сообщением об ошибке.

Также проводится тестирование правильности ввода и вывода номера счета.

    Пример: "73654108430135874305" -> "**4305"

* Модуль test_widget.py

Содержит тесты для обработки функций mask_account_card, get_date.

Применены декораторы @pytest.fixture и @pytest.mark.parametrize.

Тестируется правильность ввода и вывода номера карты или счета.

    Пример: "Visa Platinum 7000792289606361" -> "Visa Platinum 7000 79** **** 6361"

            "Maestro 7000792289606361" -> "Maestro 7000 79** **** 6361"

	        "Счет 73654108430135874305" -> "Счет **4305"

Тестируется корректный ввод и вывод даты.

    Пример: "2024-03-11Т02:26:18.671407" -> "11.03.2024"

А также проводится тестирование на наличие ошибок при отсутствии даты.

* Модуль test_processing.py

Содержит тесты для обработки функций filter_by_state, sort_by_date.

Проводится тестирование на фильтрацию по заданному статусу.

    Пример: 'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'

Произведена фильтрация по статусу «EXECUTED».

Также проводится тестирование на фильтрацию при отсутствии заданного статуса.

Проводится тестирование списка, который отсортирован по дате (date) по возрастанию (убыванию).

А также тестирует список с некорректными данными по статусу «date».
